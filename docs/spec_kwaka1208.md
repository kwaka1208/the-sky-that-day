# 実装仕様

## 概要

生年月日・時刻・観測地点を指定し、その瞬間の全天星図と観測環境をブラウザで再現するWebアプリです。天体配置、薄明、月光に加え、再解析天候、衛星夜間光、DEM地形を観測可能性へ反映します。専用バックエンドを持たず、ブラウザ内計算と実行時APIで構成します。

## 初期値と入力

- 初期日時：2000-01-01 21:00
- 初期地点：東京都、日本（緯度35.6812、経度139.7671、標高40m、`Asia/Tokyo`）
- 日付：1900-01-01〜2100-12-31
- 現地時刻：必須
- 観測地点：2文字以上の地名検索（最大5件）、現在地、または緯度経度の手動入力
- IANAタイムゾーン：検索結果または現在地の採用時にTimeAPIから取得。手動変更可能
- 最大表示等級：1.0〜6.5、0.5刻み（初期値6.5）
- 表示オプション：星座線、名称、惑星、天候、光害、地形（初期値はすべてON）

Nominatimで地点名を取得し、TimeAPIから有効なIANAタイムゾーンを取得できた場合に地点を確定します。緯度・経度だけを手動変更した場合は地点名を「カスタム地点」とし、タイムゾーンを自動更新しません。

現地日時はIANAタイムゾーンを使ってUTCへ変換します。夏時間開始時に存在しない時刻はエラー、夏時間終了時に重複する時刻は早い方を採用します。「今日」は観測地点のタイムゾーンを基準に設定します。

実表示限界は選択値、薄明・月光、取得できた天候、光害相当値の最小値です。取得不能またはOFFの条件は制約から外し、晴天・暗空とは断定しません。環境オプションをOFFにしてもAPI取得は継続し、統合・描画のみから除外します。

## 恒星・天文計算

- 名称付き主要恒星：59星
- NASA HEASARC BSC5P：3.45より暗く6.5等級以下の8,132生成元レコード
- NASAデータ内の同一座標および主要恒星から30秒角以内のレコードを実行時に重複除外
- IAU 1976歳差モデルでJ2000座標を観測日へ補正
- 太陽・月・水星〜土星：Astronomy Engine 2.1.19
- 月相、地方恒星時、地平座標、標準大気差を計算

星表は`npm run data:stars`でNASA HEASARC TAP APIから事前生成し、`src/data/nasaBrightStars.ts`へ同梱します。通常の起動、ビルド、CIでは再生成しません。

## 観測環境

### 過去天候

- API：Open-Meteo Historical Weather API
- 対象：1940-01-01以降、未来と直近5日間を除く
- 取得：観測UTC日を問い合わせ、指定UTC日時に最も近い1時間値を採用
- 変数：雲量、相対湿度、降水量、利用可能な場合は視程
- 時間分解能：1時間
- 空間分解能：約9〜25 km（地点・年代による）
- 扱い：常に再解析による推定。段階的なしきい値で限界等級を制約し、雲量と降水をCanvasへ描画

### 光害

- API：NASA GIBS WMS 1.3.0
- レイヤー：`VIIRS_SNPP_GapFilled_BRDF_Corrected_DayNightBand_Radiance`
- 対象：2012-01-19以降
- 空間分解能：約500 m、日次
- 取得：観測地点周辺の32×32 PNG
- 換算：中央50%領域の有効グレースケール画素の中央値を、実装内の指数変換式で放射輝度へ換算
- 扱い：放射輝度からBortle 1〜9相当と限界等級を概算し、夜間の地平線光へ反映
- フォールバック：2012年以前、未来、直近2日間、画像取得失敗時は2016-01-01の参照値を使用し、指定当時の値ではないことを明示

### 地形

- API：Open-Meteo Elevation API
- データ：Copernicus DEM 2021 GLO-90
- 解像度：約90 m
- 標本化：観測地点1点と、方位10°ごと×距離0.25、0.5、1、2、4、8、16、30、50 kmの合計325地点
- 取得：1回最大100件、最大4バッチ。HTTP 429は`Retry-After`または指数バックオフで最大3回再試行
- キャッシュ：緯度・経度を小数4桁へ丸めた地点キーでメモリ保持
- 計算：観測標高、地球曲率、標準屈折を考慮した最大仰角を-5〜45度へ制限し、地平線プロファイル化
- 反映：恒星・太陽・月・惑星・表示星数に共通可視判定を使用し、Canvasへ地形シルエットを描画
- 制約：建物、樹木、局所遮蔽物、年代による地形変化は含まない

## 非同期・障害処理

- `App`で天候・光害・地形を互いに待たず取得
- 入力変更時は`AbortController`で旧リクエストを中止
- request ID照合で古い応答による上書きを防止
- サービスごとに`loading`、`available`、`estimated`、`unavailable`、`error`を保持
- 1サービスの失敗で他の環境条件や天文計算を停止しない
- provider DTOをUI・天文層へ渡さず、`ObservationConditions`へ正規化
- 無効日時では環境3項目を`unavailable`とし、星図に変換エラーを表示

## 表示・操作

- 指定日時の太陽高度に応じた昼・薄明・夜の空色
- 等級とB−V色指数に応じた恒星表示
- 天候の雲ベール、光害の地平線グロー、方位別地形シルエット
- 星座線、天体名、太陽・月・惑星のON/OFF
- ドラッグ回転、0.82〜2.2倍の拡大縮小、表示リセット
- Fullscreen APIによる星空カードの全画面表示
- 表示恒星数、月相、実効限界等級
- 環境条件カードで値、状態、出典、解像度、推定上の注意を表示
- 描画更新を`requestAnimationFrame`へ集約

## モバイル追従

- タッチ可能かつcoarse pointer/no hoverの端末をモバイルとして判定
- Device Orientation APIの絶対方位またはWebKit compass headingと端末姿勢をENUカメラ座標へ変換し、透視投影
- iOSの明示権限、コンパス追従ON/OFF、5秒無応答時の再試行
- 相対方位しか取得できない場合は通常の手動表示へフォールバック
- 追従中は手動ドラッグ・ズームを停止し、中央付近の名称付き天体を表示
- センサー許可後はGeolocation APIで現在地を監視
- 前回試行から30秒未満、または前回採用位置から100m未満の移動は無視
- 逆ジオコーディングとタイムゾーン取得の両方に成功した位置のみ採用

## 開発・ビルド・デプロイ

```bash
npm ci
npm run dev
npm run typecheck
npm run build
npm run preview
```

`npm run build`は`tsc --noEmit && vite build`です。ViteのPages用baseは`/the-sky-that-day/`です。GitHub Actionsは`main`へのpushまたは手動実行でNode.js 22、`npm ci`、本番ビルド、`dist`のPagesデプロイを行います。lint、テスト、星表再生成はCIに含みません。

```bash
npm run typecheck
npm run build
git diff --check
```

## 制約

- 天候は再解析であり地点実測ではない
- Bortle階級は衛星画像のグレースケール値から実装内の式で換算した概算値
- 2012年以前、未来、直近2日間、欠測時の光害は2016年参照値であり履歴再現ではない
- 地形は2021年版DEM由来で建物・樹木を含まない
- 外部APIのCORS、停止、レート制限により一部条件が取得できない場合がある
- 環境API、地名検索、タイムゾーン判定、Webフォントにはインターネット接続が必要
